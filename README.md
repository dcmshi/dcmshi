### \* GAMES

The bulk of it. Mostly things I wanted to play with friends.

- [`set-game`](https://github.com/dcmshi/set-game) — realtime pattern matching, in the browser
- [`sichuan-mahjong`](https://github.com/dcmshi/sichuan-mahjong) — play sichuan mahjong with friends
- [`bust-a-move`](https://github.com/dcmshi/bust-a-move) — the classic, originally in Turing
- [`blocks`](https://github.com/dcmshi/blocks) — puzzle game, no dependencies

### \* THE LIBRARY

Tools for learning things, usually built while learning that thing.

- [`fact-fluency`](https://github.com/dcmshi/fact-fluency) — have fun learning arithmetic
- [`chinese-anki-builder`](https://github.com/dcmshi/chinese-anki-builder) — turn Chinese EPUBs into Anki decks with jieba + CC-CEDICT
- [`system-design-quizzer`](https://github.com/dcmshi/system-design-quizzer) — generate multiple choice from systems design reading
- [`crafting-interpreters`](https://github.com/dcmshi/crafting-interpreters) — working through the book, one bytecode VM at a time

### \* THE GYM

- [`oly-program-generator`](https://github.com/dcmshi/oly-program-generator) — olympic weightlifting programs, generated
- [`plate-converter`](https://github.com/dcmshi/plate-converter) — plate math for kg ↔ lbs bars

### \* HOTLAND

Things built to stop doing something by hand.

- [`transit_planner`](https://github.com/dcmshi/transit_planner) — routing and trip planning
- [`job-tracker`](https://github.com/dcmshi/job-tracker) — scrapes application email into a spreadsheet
- [`job-autofiller`](https://github.com/dcmshi/job-autofiller) — fills the same fields into the 40th job form
- [`expense-tracker`](https://github.com/dcmshi/expense-tracker) — log expenses by photo or voice
- [`task-scheduler`](https://github.com/dcmshi/task-scheduler) — adaptive scheduling, in Go
- [`chatime-bot`](https://github.com/dcmshi/chatime-bot) — orders bubble tea for the team

### \* THE RUINS

- [`pebbledoro`](https://github.com/dcmshi/pebbledoro) — pomodoro timer for the Pebble watch, in C
- [`math-notes`](https://github.com/dcmshi/math-notes) — TeX, since 2016
- [`rebase-demo`](https://github.com/dcmshi/rebase-demo) — git gud at rebase
- [`game-of-life`](https://github.com/dcmshi/game-of-life) — Conway's, naturally
- [`django-sudoku-solver`](https://github.com/dcmshi/django-sudoku-solver) — a solver that insisted on being a website
